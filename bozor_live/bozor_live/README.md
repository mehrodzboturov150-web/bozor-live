# Bozor.tj — сайт объявлений с сервером

## Запуск на компьютере

Установите Python 3.10+ и выполните в папке проекта:

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows:
# .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Откройте http://localhost:5000

## Размещение в интернете

Проект подходит для Python-хостинга с постоянным диском. Укажите команду запуска:

```bash
gunicorn app:app --bind 0.0.0.0:$PORT
```

Установите переменную окружения `SECRET_KEY` (случайная длинная строка). Для постоянного хранения задайте `DATABASE_PATH` и `UPLOAD_DIR` в папках с сохраняемым диском. Если хостинг удаляет файлы после перезапуска, база и фото будут потеряны.

## Возможности

Регистрация и вход, общая база SQLite, публикация с фото, поиск и категории, избранное, личные объявления, чат покупателя с продавцом. Сообщения обновляются при повторном открытии чата, без push-уведомлений.

## Перед публичным запуском

Рекомендуются HTTPS, резервное копирование базы и изображений, CSRF-защита, ограничение частоты запросов, модерация объявлений и защита от спама. Текущая версия — MVP, не готовая к большой нагрузке без доработок.
