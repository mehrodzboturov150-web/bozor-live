# Bozor.tj — обновлённый сайт объявлений с акцентом на автомобили

Это самостоятельный дизайн Bozor.tj, вдохновлённый удобством автомобильных классифайдов. Интерфейс не копирует торговые марки, логотипы или чужие изображения. Есть все старые функции, расширенный поиск автомобилей, отдельные автомобильные характеристики, галерея до **6 фотографий**, подробная страница объявления и управление своими объявлениями.

## Структура

```text
app.py                     # точка входа для Gunicorn / Render
bozor/__init__.py          # конфигурация, регистрация API, CSRF и HTTP-защита
bozor/db.py                # подключение SQLite, недеструктивные изменения схемы
bozor/auth.py              # регистрация, вход, выход
bozor/listings.py          # поиск, объявления, автомобильные характеристики, фото
bozor/messages.py          # личная переписка
bozor/media.py             # проверка, обработка и выдача изображений
templates/index.html       # семантическая разметка интерфейса
static/css/main.css        # стили сайта
static/js/app.js           # взаимодействия, каталог, просмотр, публикация, чат
tests/test_api.py          # API тесты
```

## Запуск локально

Требуются Python 3.10+ и зависимости из `requirements.txt`.

```powershell
cd "C:\Users\User\Desktop\bozor_live\bozor_live"
python -m pip install -r requirements.txt
python app.py
```

Откройте `http://localhost:5000`.

## Render

Если GitHub проект содержит пути `bozor_live/bozor_live/app.py`, используйте:

| Параметр Render | Значение |
| --- | --- |
| Root Directory | `bozor_live/bozor_live` |
| Build Command | `pip install -r requirements.txt` |
| Start Command | `gunicorn app:app --bind 0.0.0.0:$PORT` |
| Health check | `/health` |
| Environment | `SECRET_KEY` — случайный секрет, **никогда не публикуйте его** |

Старые таблицы `users`, `listings`, `messages` и `favorites` остаются. Приложение добавляет таблицы `car_details` и `listing_photos` и не очищает старые данные.

### Постоянная база данных и фото

На бесплатном Render SQLite и загруженные файлы на локальном диске могут быть удалены при перезапуске или следующем деплое. Для долговременного хранения нужен платный экземпляр с persistent disk **или** внешняя база и объектное хранилище. Для диска Render задайте:

```text
DATABASE_PATH=/var/data/bozor.db
UPLOAD_DIR=/var/data/uploads
```

Обе переменные задаются только после подключения диска, смонтированного как `/var/data`. До включения новой версии перенесите старую `bozor.db` и папку фотографий на постоянное хранилище, если необходимо сохранить текущих пользователей и объявления. Не добавляйте `bozor.db`, `.env`, ключи или реальные данные пользователей в GitHub. Регулярно делайте внешние резервные копии диска.

## Пример автомобильного объявления

Новые объявления категории «Автомобили» поддерживают: марку, модель, год выпуска, пробег, коробку передач, топливо, привод, кузов, двигатель, цвет, расположение руля и состояние. Для старых объявлений неизвестные поля **не выдумываются** — пользователи могут самостоятельно отредактировать их.

## Важно перед массовым запуском

Проект — MVP. Нужны лимиты запросов, модерация контента, борьба со спамом, восстановление пароля, резервные копии и мониторинг. Чат работает через HTTP-запросы, без push-сообщений. Не принимайте реальные платежи без отдельной платёжной интеграции и проверки безопасности.
